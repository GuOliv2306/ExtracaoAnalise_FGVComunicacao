# 🚀 Guia Rápido: Privacidade do Repositório

## Passos Simples para Tornar Privado

### No GitHub Web:
1. Vá para **Settings** → Role para baixo → **Danger Zone**
2. Clique **"Change repository visibility"**
3. Selecione **"Make private"**
4. Digite o nome do repositório para confirmar
5. ✅ Pronto!

### Comandos Úteis para Alternativas:

```bash
# Criar backup local
git clone https://github.com/GuOliv2306/ExtracaoAnalise_FGVComunicacao backup_local

# Criar novo repositório privado (no GitHub primeiro)
git clone https://github.com/GuOliv2306/MEU_REPOSITORIO_PRIVADO

# Copiar arquivos específicos
cp -r backup_local/aula_XX/ MEU_REPOSITORIO_PRIVADO/
```

## ⚡ Dica Importante

**Antes de tornar privado, considere:**
- O professor conseguirá ver suas atualizações?
- Você precisa compartilhar código com colegas?
- Prefere um repositório separado para anotações?
